# Portfolio — Kylian Rousseau

Portfolio personnel d'étudiant en BUT Informatique.  
Design **Material 3 Expressive** avec palette bleue.

## Structure

- `index.html` — Page principale (single-page)
- `style.css` — Design system M3 Expressive (tokens, composants)
- `script.js` — Animations scroll, menu mobile, tilt cards

## Lancer

Ouvrir `index.html` dans un navigateur ou utiliser un serveur local :

```bash
npx serve .
```
