# Portfolio — Kylian Rousseau

Portfolio personnel d'un étudiant en BUT Informatique.  
Limoges, France — 2026

## Structure

- `index.html` — Page d'accueil du portfolio (Hero, À propos, Stack technique, Projets phares, Contact)
- `style.css` — Design system M3 Expressive (tokens, composants, mode sombre / clair)
- `script.js` — Animations scroll, navigation active, menu mobile, tilt cards
- `projets/` — Pages détaillées de chaque projet :
  - `legrand.html` — Projet Industriel Legrand (Fiche de sécurité presse & modes opératoires)
  - `sisyphe.html` — Sisyphe.io (Sokoban revisité, lauréat Trophées NSI 2024)
  - `latice.html` — Latice (Jeu de plateau tactique Java & JavaFX)
  - `kathara.html` — Simulation réseau Kathará (Routage, DHCP, DMZ, Wireshark)
  - `python-games.html` — Suite de mini-jeux terminal & IA (SAE 1.01-1.02)
  - `project-page.css` & `project.js` — Styles et scripts dédiés (lightbox modale, synchronisation thème)
- `assets/img/` — Vignettes, bannières et visuels haute définition des projets

## Lancer

Ouvrir le lien : `https://kylian-rousseau.netlify.app/` dans un navigateur

Ou lancer un serveur local dans le dossier du projet :

```bash
npx serve .
```
